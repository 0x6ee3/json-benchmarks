# json-benchmarks

Super simple framework benchmark.

## Requirements

Gobal:
- bash
- wrk

Test specific:
- jdk
- nodejs
- go

## Benchmark setup

For the rules for the server implementation see [TechEmpower's benchmark rules](https://www.techempower.com/benchmarks/#section=code). Only the plaintext and json tests are used.

Test execution done with [wrk](https://github.com/wg/wrk) installed by `brew install wrk`.
